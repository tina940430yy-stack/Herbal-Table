# 草本餐桌計畫｜互動網站原型

這是一個純 HTML、CSS、JavaScript 的前端網站專案，無需安裝套件或啟動伺服器。

## 開啟方式

1. 解壓縮整個 ZIP 資料夾。
2. 開啟 `index.html`，建議使用最新版 Chrome、Edge 或 Safari。
3. 請保留 `index.html`、`styles.css`、`app.js` 與 `assets/` 的相對位置，不要把它們分開搬動。

## 互動說明

- **桌機**：點中央的旋轉按鈕，餐桌會旋轉並隨機停在一道料理，接著開啟料理資訊卡。
- **手機**：直接用手指拖轉餐桌；放手後餐桌會續轉並隨機停在一道料理。點中央圓區也可以抽一道料理。
- 點選餐桌周圍的料理、料理探索中的卡片或植物圖鑑中的植物，都能開啟對應資料卡。
- 料理探索支援分類、搜尋與收藏；植物圖鑑支援分類和搜尋。
- 導覽包含首頁、料理探索、植物圖鑑、料理實驗日誌與飲食文化。

## 專案檔案

- `index.html`：網站頁面結構與內容區塊
- `styles.css`：配色、版面、手機／桌機響應式樣式與轉盤操作樣式
- `app.js`：料理與植物示例資料、SVG 插圖、搜尋、收藏、轉盤與資訊卡互動
- `assets/`：後續可放置正式料理照片、植物照片或其他圖片素材

## 關於內容

目前的料理與部分植物應用均為畢製討論階段的示意內容，不是已完成查核的食譜或食用建議。實際製作前，請確認植物品種、可食部位、食材處理方式、食安資訊及資料來源；「全株可用」不等於「全株可食」。研究過程、測試結果與訪談內容應以團隊實際完成的紀錄取代示例。
